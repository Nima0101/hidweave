# Community code of conduct

Treat participants respectfully regardless of background, identity or experience.
Critique technical ideas with evidence; welcome questions and corrections. Avoid
harassment, threats, discriminatory language, sexualized conduct, personal attacks,
and publication of private information without permission.

This applies in repository discussions, issues, pull requests and project-related
community spaces. Maintainers may edit or remove harmful contributions and limit
participation, proportionately and with an explanation where feasible.

Report concerns privately through the repository owner's
[GitHub profile contact options](https://github.com/Nima0101). If a private channel
is unavailable, request one without publishing sensitive details. Maintainers will
protect reporter privacy as far as practical and avoid retaliation.
